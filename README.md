# 夜行者 NIGHT PILOT · 自动驾驶感知检测实验室

工程心理学作业一：信号检测论（SDT）交互式实验网站。
场景：**自动驾驶目标识别**——你是感知系统安全标定员，在夜间测试场判断闪现画面中是否有行人。

## 如何运行

**双击 `index.html` 即可在浏览器中运行。** 纯前端实现，无需安装任何环境、无需联网、无需启动服务器。

推荐 Chrome / Edge / Firefox 最新版。

## 操作说明

| 操作 | 方式 |
|---|---|
| 作答「有行人 · 制动」 | 按 `F` 键或点击红色按钮 |
| 作答「无行人 · 通过」 | 按 `J` 键或点击绿色按钮 |
| 选择难度 | 简报页点击天气预设卡（晴朗 d'=2.5 / 雨夜 d'=1.5 / 浓雾 d'=0.8），或拖动滑块连续自定义 d'（0.5~3.5），滑块下方有实时难度解释 |

流程：注视点(600ms) → 画面闪现(约700~950ms，限时刺激) → 噪点掩蔽(200ms) → 作答 →
**即时反馈**（每次判断后立即显示本次是 击中 / 漏报 / 误报 / 正确拒斥 及场景化解释），共 24 试次。

## SDT 参数定义

- **信号**：画面中真实出现的行人剪影，先验概率 **P(S) = 0.3**（深夜行人稀少）
- **噪音**：塑料袋、垃圾桶、反光路牌、灌木阴影、眩光等"形似行人"的干扰物
- **击中 H**：有行人且报警 → 车辆制动，避免事故
- **漏报 M**：有行人但未报警 → 撞人事故（代价最高）
- **误报 FA**：无行人却报警 → 幽灵刹车（后车追尾风险）
- **正确拒斥 CR**：无行人且放行 → 顺利通过

### 生成模型

每个试次：先按 P(S)=0.3 抽签决定有无行人；再从 N(0,1)（无行人）或 N(d',1)（有行人）
采样一个"证据值"（Box-Muller 变换），映射为画面中目标物的清晰度（透明度）。
d' 越小，两种画面越相似，判断越困难。

### 指标计算（js/math.js）

- d' = z(P(H)) − z(P(FA)) —— 敏感性（分辨能力）
- c = −[z(P(H)) + z(P(FA))] / 2 —— 判断标准（c>0 保守，c<0 宽松）
- β = exp(d'·c)；AUC = Φ(d'/√2)
- z 分数由 Acklam 有理逼近的 Φ⁻¹ 计算；采用 Hautus log-linear 边界校正
  （计数 +0.5 / 总数 +1），避免击中率=1 或误报率=0 时出现无穷大

## 功能清单

- 交互式检测游戏：逐次试次判断、刺激限时呈现、难度（d'）预设三档 + 滑块连续自定义（0.5~3.5，附实时解释）
- 完整 SDT 结果页：混淆矩阵、P(H)/P(FA)/d'/c/准确率、"准确率陷阱"讲解、判断风格解读
- 概念实验室（加分项）：d'/c/σ(SN) 三个滑块联动双分布图、ROC 曲线与 z 变换 ROC（z 分数下 ROC 为直线，斜率=σ(N)/σ(SN)），实时显示 P(H)/P(FA)/β/AUC
- 多局对比与排行榜（加分项）：localStorage 保存每局成绩，ROC 图上叠加全部实测点，按难度排行
- 场景化界面（加分项）：夜间驾驶舱 HUD 美学，Canvas 实时渲染雨/雾/透视道路/行人剪影，全部图表按 devicePixelRatio 高清渲染
